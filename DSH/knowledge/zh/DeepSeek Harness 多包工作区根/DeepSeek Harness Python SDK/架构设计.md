模块由两个独立的 Python 包组成：
- `python/sdk`（`deepseek-harness-sdk`）：对外暴露的 SDK 层。`api.py` 中的 `DeepSeekHarness`/`Session` 是高层 API，负责启动进程、初始化、发起 `session/prompt` 并基于 `session.status=idle` 与 `turn/end` 事件组装 `RunResult`；`client.py` 中的 `HarnessClient` 是底层 JSON-RPC 客户端，使用 `subprocess.Popen` 拉起 dsh 二进制，通过独立 reader/stderr 线程按行解析 JSON-RPC 消息，用 `queue.Queue` + `threading.Lock` 实现请求-响应匹配、通知分发与订阅过滤（支持按 session 及 subagent 父子关系过滤）；`models.py` 定义共享的 `Notification`/`IncomingRequest`/`InitializeResponse` 等 Pydantic/dataclass 类型；`errors.py` 集中异常。
- `python/sdk-runtime`（`deepseek-harness-runtime-bin`）：运行时载体包，通过 `hatch_build.py` 在构建时注入平台特定的单文件 Node 可执行产物（`runtime/deepseek-harness-sdk-runtime-<plat>-<arch>`），并在安装后暴露 `dsh` 控制台脚本。`__init__.py` 提供 `resolve_bundled_launch_args()`，根据 `DSH_RUNTIME_MODE` 环境变量在 exe 模式（生产）与 node 模式（开发）之间切换，并校验 ripgrep sidecar 与 macOS spawn-helper。
依赖方向单向：SDK → runtime 包（仅用于定位可执行路径），两者均不反向依赖；SDK 通过 `uv` 的 editable source 指向 `sdk-runtime`，使本地开发无需发布 wheel。
