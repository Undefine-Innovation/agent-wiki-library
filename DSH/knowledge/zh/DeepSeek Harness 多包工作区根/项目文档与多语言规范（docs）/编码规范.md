- 每篇文档以 `*.md`（英文）、`*.zh.md`（中文）、`*.i18n.yaml`（记录两侧 blob hash）构成不可分割的三元组，PR 必须同时提交或全部排除。
- 中文文档 H1 后立即附带 `[English](foo.md) | 中文` 语言切换器，英文文档反向附带 `[中文](foo.zh.md)`，生成源可省略切换器。
- 相对文档链接在英文侧指向 `.md`、中文侧指向 `.zh.md`，且保持相同的语义目标与 query/fragment 后缀。
- 代码块（含 info string 与注释）在双语间必须字节一致，表格行列数、列表种类与序号、标题层级与顺序必须一一对应。
- 术语统一以 `i18n/terminology.md` 为准，首次出现时在中文侧标注英文原词，未收录术语不得自行发明译法。
- 子系统文档采用“一页一子系统”形式，聚焦该子系统的数据结构、服务注册与事件契约，并在必要时嵌入生成的 Cordis API 章节。
