文档按主题分层组织：顶层为跨模块概览（architecture.md、module-graph.md、capability-seams.md、glossary.md、development.md、testing.md 等）；subsystems/ 下每个子系统一份 `*.md` + `*.zh.md` + `*.i18n.yaml` 三元组，作为该子系统的数据结构、服务与事件参考；cordis-api/ 与 cordis-tutorial/ 分别提供 Cordis 插件框架 API 参考与分步教程；user/ 面向使用者，分为 guide/（使用指南）和 develop/（开发实践，含 basic/framework/practice 子目录）；cookbook/ 提供扩展添加、代码评审等实操手册；postmortem/ 以编号记录历史故障复盘；i18n/ 集中维护翻译规则、术语表与说明。所有文档遵循严格的“三文件配对”契约：每篇英文 `foo.md` 对应中文 `foo.zh.md` 与一致性记录 `foo.i18n.yaml`（记录两侧最新确认时的 git blob hash），由 `verify-translation-pairing` 门禁强制校验标题层级、表格行列数、列表形态、代码块字节一致性与链接目标，确保双语文档在结构与语义上严格对齐。
