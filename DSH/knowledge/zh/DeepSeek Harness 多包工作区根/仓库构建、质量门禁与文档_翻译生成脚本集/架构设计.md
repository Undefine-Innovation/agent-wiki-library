本模块是仓库级脚本集合，按职责分为四类：
- 编排入口：`run-gates.ts` 定义 `Mode` 联合（ci-primary / ci-static / ci-coverage / doc-sync 等），通过 `gatesForMode` 组装 Gate 图（id/needs/after/env/allowFailure/streamOutput），内置有向无环依赖解析、`runGates` 并发调度器与 `runGate` 子进程执行边界；`build.ts` 基于 `client-build-environment.ts` 选择 profile 并顺序调用 `build:lib`、`build:web`。
- 共享基础设施：`pnpm-invocation.ts` 从 `npm_execpath` 构造 shell-free 子进程命令；`ts-project.ts` 提供 `TypeScriptProject` 类，将 host/client tsconfig 及其 projectReferences 扁平化为单一 `ts.Program` 供语义检查脚本复用；`markdown.ts`、`slot-walk.ts`、`repo-files.ts`、`cordis-yaml.ts`、`cordis-walk.ts` 提供 Markdown/Cordis/仓库文件遍历能力。
- 验证门（verify-*）：每个 `verify-*.ts` 对应一个 pnpm script，通常配有同名 `.spec.ts` 单元测试，覆盖断言、路径发现、空语料防护等边界。
- 生成器（gen-*）与翻译管线：`translation-pairing.*`、`translation-brief.*`、`translation-prompt.*`、`merge-translation-pairing.*` 构成双语文档配对、提示词生成与合并流水线，配合 `fixtures/translation-prompt/` 与 `snapshots/` 中的期望数据做回归测试。
依赖方向单向向内：gate 编排 → 具体 verify/gen 脚本 → 共享基础设施；所有外部工具（pnpm/vitest/tsc）均通过 `pnpmInvocation` 或 `spawn` 以无 shell 方式调用，平台差异由各自 gate 内处理。
