- 服务包默认导出服务类，函数插件仅命名导出 `name`/`inject`/`Config`/`apply`，禁止混用默认导出以免 Loader 丢弃命名空间。
- 可选服务通过 `ctx.get(name)` 读取，已声明注入才使用 `ctx.<name>` 属性代理，避免拓扑敏感的全局读取。
- 能力域采用 Service Definition / Service Provider / Consumer 三角色拆分，公共接口面向所有 Consumer 设计而非单一调用方。
- 每个包拥有 `./invariant` 文件注册运行时契约，空实现需提供 `No runtime invariant:` 理由并通过 `verify-package-invariants` 校验。
- 包 tsconfig 继承 `tsconfig.base.json`（客户端继承 `tsconfig.base.client.json`），`rootDir: src`、`outDir: lib/types`，并在一个聚合中引用工作区依赖与 `runtime-diagnostics/invariants`。
- 测试位于包级 `tests/` 目录而非 `src/__tests__/`，产品可见插件需包含非单元 REAL 组合测试，通过 Loader 启动完整 app/process 并断言用户可见输出。
- 包 README 必须覆盖用途、配置、扩展点与 Model Experience，并在末尾列出已知限制与延期工作或使用允许名单豁免。
