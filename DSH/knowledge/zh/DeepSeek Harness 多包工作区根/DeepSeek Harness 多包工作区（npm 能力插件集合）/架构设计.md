本模块是 pnpm workspace 下的多包聚合根，每个子目录是一个独立的 npm 包（命名空间 `@deepseek-ai/dsh-*`），由 `README.md` 中的分组表划分为能力家族：核心产品 API（core）、远程 BFF（api）、类型图生成（typert）、会话数据面（session/session-query）、LLM 抽象与提供者（llm/e2b）、Shell/Terminal/Code-runtime/Sandbox 执行栈、FS/LSP/Web 等模型工具、Subagent/Jobs/Workflow 编排、Attachment/Spill/Storage/Settings/Credentials 持久化、Host/Client 双端 Web-GUI、以及 boot/bundle/preset/extensions/hooks 等装配层。依赖方向遵循“Service Definition / Service Provider / Consumer”三角色分离：插件通过 Service Definition 接入，禁止直接依赖具体 Provider；`dsh-agent-loop` 可替换，UI/Hook/Tool 插件统一依赖 `dsh-agent`。包间依赖关系由 CI 生成的模块图维护，新增包必须加入现有分组并更新分组 README。
