模块由一个 pnpm workspace (`native/landlock-run`) 构成，采用「入口 JS 包 + 每平台预编译二进制包」的分发模型：`packages/entry/` 暴露 `launcherPath()`、`probe()`、`grantArgs()` 等小 API；`packages/linux-x64`、`packages/linux-arm64` 通过 `prebuilds.json` 声明各自平台与二进制清单，由 `scripts/build.ts` 在对应 Linux 架构上调用 `musl-gcc -static` 编译 `packages/entry/src/main.c`（C11，约 300 行内核 UAPI 封装）生成 `bin/landlock-run`。构建脚本强制 NATIVE-ONLY，禁止交叉编译，CI 各架构 runner 作为「记录构建者」。发布流程由 `scripts/{assemble-prebuilds,pack-release,publish-release,verify-release,...}.mjs` 串联，将 CI 产物装配进平台包并校验 ELF 架构。CLI 契约（argv、退出码、报告行）在 `docs/cli-contract.md` 中固化，JS 层仅做路径解析与参数拼装，不实现沙箱逻辑。测试位于 `test/`，`launcher.test.js` 直接对真实二进制进行端到端行为验证（含世界证明：拒绝写未授权路径、规则集跨 execve 继承）。
