- 每个平台包通过 `packages/<name>/prebuilds.json` 声明 `platform` 与 `binaries` 清单，构建脚本据此推导目标，新增工具需同时登记到 `scripts/build.ts` 的 TOOLS 表。
- 二进制产出统一放在 `packages/<name>/bin/` 下并以 `.gitignore` 忽略，仅通过 npm 包的 `prepack` 钩子打包进 tarball，避免把原生产物提交到仓库。
- CLI 契约（argv 语法、退出码、stderr 前缀 `landlock-run: `、`--probe` 输出）在 `docs/cli-contract.md` 中固化，任何变更需伴随版本号升级并在 release notes 中说明。
- 错误处理遵循 fail-closed：当内核无法强制执行 Landlock 或 grant 根目录不可打开时，启动器直接退出 125 且不执行被包装命令，由消费者根据 `probe()` 结果选择降级策略。
- 测试通过直接 `spawnSync` 调用真实二进制来断言 CLI 行为与沙箱效果（包括写入被拒、规则集跨 execve 继承），而非 mock 系统调用。
