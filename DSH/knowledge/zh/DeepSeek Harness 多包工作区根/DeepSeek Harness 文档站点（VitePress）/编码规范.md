- 文档页面通过 `docs.ts` 中的声明式数组集中描述，使用 `pairedPages`/`mirroredPages` 辅助函数按 locale 展开，而非直接编写 VitePress 路由配置。
- 每个页面的中文/英文标签、侧边栏分组、章节顺序均通过对象字面量显式声明，并由 `sectionSpec` 校验位置，新增页面必须同时提供双语 label 与 section。
- 侧边栏分组标题统一来自 `sections` 常量，禁止在 `sidebar()` 中硬编码分组文本，以保证中英文站点分组顺序一致。
- 导航项与侧边栏条目统一通过 `routeLink`/`landingLink` 从清单派生 URL，避免手写路由字符串导致与清单不同步。
- 生产构建前通过 `cleanDocSiteOutput` 校验输出目录必须是站点根的子目录且非符号链接，防止误删父级目录。
- Markdown 渲染规则在 `markdown.config` 中拦截 text/code_inline/fence 并转义 Vue 插值标记，确保生成的 HTML 安全。
