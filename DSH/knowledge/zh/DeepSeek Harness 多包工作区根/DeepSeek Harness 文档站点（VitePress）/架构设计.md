模块以 `.vitepress/config.ts` 为 VitePress 入口，使用 `withMermaid` 插件并配置 `zh-CN`/`en-US` 双 locale；所有页面源码位于仓库根目录的 `docs/` 下，本模块仅维护一份 `docs.ts` 声明式清单（`homeAndGuide`、`develop`、`cordisTutorial`、`subsystemsReference`、`reference` 等数组），通过 `pairedPages`/`mirroredPages` 辅助函数按 locale 展开成 `DocsPage[]`，再由 `build.ts` 调用外部脚本 `scripts/project-doc-site.ts` 把对应 Markdown 拷贝到 VitePress 的 `srcDir: .generated` 中完成“投影”。导航栏与侧边栏由 `config.ts` 中的 `sidebar()`/`guideSidebar()`/`moduleNav()` 根据 `localeCollections` 与 `sectionSpec` 动态生成，保证新增集合时导航与侧边栏同步。开发模式下通过自定义 Vite 插件监听源文件变化并在中间件里提供原始 Markdown 与 `llms.txt` 路由；生产构建通过 `buildEnd` 钩子输出原始 Markdown 副本与 `llms.txt`。公共静态资源放在 `public/`，样式与滚动行为通过内联 CSS/JS 注入，避免额外主题目录。
