### capability seam
- 定义：一种可替换的能力抽象，包含三个角色：Service Definition（定义接口与 `ctx.<key>`）、一个或多个 Service Provider（具体实现）、以及 Consumer（使用者）。例如 `shell` 能力由 `dsh-shell`（定义）、`dsh-bash-local`/`dsh-bash-sandbox`（provider）、`dsh-tool-bash`（consumer）组成。新增能力必须同时设计三者，不能只改单一角色。
- 别名：seam、能力接缝

### profile
- 定义：dsh 启动时的命名组合模板，保存在 Harness home 中，列出要堆叠的 bundle、安装的外部插件以及用户自己的 `cordis.patch.yml`。官方 shipped 的 profile 包括 `web`、`headless`、`sdk`、`sdk-minimal`、`acp`。不同 profile 决定一次启动是否支持 live patch reload。
- 别名：dsh --profile、配置文件

### bundle
- 定义：Cordis 配置行及其挂载代码的分发格式，用于把一组 patch 层打包分发；bundle 插入的内容仍可被上层 layer 覆盖。每个 bundle 在自身 `package.json` 的 `dsh.bundle` 字段指向其 patch 文件。
- 别名：dsh bundle、补丁包

### turn
- 定义：一次会话中对已准入输入的完整消费过程，结束于模型与其工具停止或终端策略介入；一个 turn 包含零个或多个 step。
- 别名：轮次

### step
- 定义：一次模型请求加上该请求响应引发的工具执行；一个 turn 可以包含多个 step。
- 别名：步骤

### goal
- 定义：附加到现有 session 上的持久化完成目标，具有 revisioned 的阶段（active/paused/blocked/complete）和 goal-round 上限；`blocked` 保留策略码和解释。goal 是状态而非调度器，session log 是其唯一事实来源。
- 别名：目标

### goal round
- 定义：允许当前 goal 继续的一个周期；同一 session 中的 driver 会把一个 goal round 物化为一个 goal 来源的 turn，同 session 内无关的人类 turn 不消耗 goal-round 配额。
- 别名：目标轮次

### Ralph loop
- 定义：面向不可变目标的单前台 fresh-agent 工作流，由 workflow 和 subagent 原语组合而成，不是 same-session goal、agent-loop 模式、scheduler 或通用 workflow-script 特性。
- 别名：Ralph 循环

### Ralph handoff
- 定义：从一个继续的 Ralph round 传递到下一个 round 的规范化有界结构化报告，包含状态、摘要、证据、下一步和 blocker 文本；它补充共享 workspace，但不替代 workspace 作为权威。
- 别名：Ralph 交接

### scope / agent scope
- 定义：per-agent 的注册单元：tool、prompt section、variable、restriction、listener 等贡献要么 global（对所有 agent 可见），要么 scoped（仅对某个 scope key 可见）。scoped 注册不会继承给 subagent；子树行为通过 lineage 数据表达而非 scope 结构。
- 别名：作用域、agent.ctx

### shadowing
- 定义：最匹配优先的名称解析：scoped 的 tool/section/variable 会替换同名的 global 条目，但仅对该 scope 生效；这是 per-agent persona 和 per-agent tool-variant 机制的基础。
- 别名：遮蔽

### human command
- 定义：以斜杠前缀的指令，由 human-facing adapter 通过 `ctx.commands` 解释和执行，不会变成 model message；区别于 model-facing tool 和通过 `ctx.shell` 执行的 shell 命令。
- 别名：人类命令、slash command

### model-visible ⟺ logged
- 定义：任何到达模型请求的内容都必须能从 session log 重建；因此新的 model-visible 输入需要新增 session event。这是 dsh 的核心不变式，贯穿 session、transcript、telemetry、persistence。
- 别名：模型可见即记录

### application launch
- 定义：受支持的 Node 应用统一通过 `dsh` CLI 的 named profile 启动（`web`、`headless`、`sdk`、`sdk-minimal`、`acp`）；禁止 package bin、demo、public SDK argv 绕过此入口。Python SDK 也遵循相同架构，通过包装 `dsh --profile sdk` 启动。
- 别名：应用启动

### vendored package
- 定义：以源码副本形式直接纳入仓库的第三方包（如 `vendor/` 下的 Cordis），通过 manifest 固定上游 SHA，并由专用 sync 流程更新；这些包被 rescope 并标记 `private: true`。
- 别名：内嵌包、vendor 包
