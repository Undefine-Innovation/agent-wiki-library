## 简介
Agent Diva 是一个轻量、可扩展的本地个人 AI 助手框架，提供 CLI、TUI 和桌面 GUI。通过 Gateway 进程统一管理会话、路由与通道连接，消息经 Agent Loop 调用 LLM 与工具后返回对应通道。你可以快速在本地运行并立即开始对话。

## 环境要求
- Rust 1.80+（MSRV；推荐使用 rustup 安装）
- 可选：just（用于便捷工作区命令）
- 仅构建/运行 GUI 时需要：Node.js v18+ 以及 npm/pnpm

说明：
- 工作区根 Cargo 配置声明了最低 Rust 版本为 1.80.0。
- README 明确列出 Rust 1.80+、可选 just，以及 GUI 所需的 Node.js v18+ 与包管理器。

## 从源码安装
推荐方式（使用 just）：
- 克隆仓库并进入项目目录
- 执行构建与安装

也可直接使用 cargo：
- 构建所有 crate
- 安装 CLI 二进制到本地

说明：
- justfile 提供了 build、install 等快捷任务，内部调用 cargo 完成构建与安装。
- 若未安装 just，可直接使用 cargo 命令达到相同效果。

```bash
git clone https://github.com/ProjectViVy/agent-diva.git
cd agent-diva
just build
just install
```

或等价使用 cargo：
```bash
cargo build --all
cargo install --path agent-diva-cli
```

## 初始化配置
首次运行前，建议初始化配置与工作区模板：
- 运行 onboard 向导，创建默认配置与工作区
- 如需刷新默认值而不覆盖用户已有设置，可使用 config refresh

常用配置管理命令：
- 查看解析后的实例路径
- 校验配置
- 运行健康检查（doctor）

```bash
agent-diva onboard
agent-diva config refresh
agent-diva config path
agent-diva --config ~/.agent-diva/config.json config validate
agent-diva --config ~/.agent-diva/config.json config doctor
```

说明：
- onboard 会引导你选择 Provider、模型等，并生成工作区模板。
- config loader 支持从配置文件与环境变量合并加载，并进行别名与路径规范化。

## 最小化配置（至少一个 Provider API Key）
要能在 TUI/CLI 中聊天，只需在配置文件中添加至少一个 Provider 的 apiKey，并指定默认代理与模型。

示例结构（以 OpenRouter 为例）：
- providers 下新增 openrouter 条目，包含 apiKey
- agents.defaults 中指定 provider 与 model

注意：
- 如果直连原生端点（例如 DeepSeek），请使用原始模型 ID（如 deepseek-chat），不要加 provider/model 前缀。
- 环境变量也可覆盖配置项（如 OPENAI_API_KEY、ANTHROPIC_API_KEY 等）。

## 基础使用方法
- 启动交互式 TUI 进行对话
- 发送单条消息
- 查看状态、通道与 Provider 信息
- 启动 Gateway（包含通道与定时任务）

常用命令：
```bash
agent-diva tui
agent-diva agent --message "你好，Agent Diva！"
agent-diva status
agent-diva channels status
agent-diva provider list
agent-diva gateway run
```

说明：
- TUI 提供终端内交互界面，无需配置通道即可本地使用。
- Gateway 会启动 Agent Loop、已启用通道与定时任务。

## 故障排除提示
- 无法找到 Rust 或版本过低：确保已安装 Rust 1.80+，并通过 rustup 切换至正确版本。
- 找不到 just：使用 cargo 直接构建与安装，或安装 just 后再执行工作区命令。
- 配置无效或未生效：使用 agent-diva config validate 校验；使用 agent-diva config doctor 诊断运行时就绪情况；必要时使用 agent-diva config refresh 刷新默认值。
- 环境变量未生效：确认环境变量名与大小写正确（如 OPENAI_API_KEY、ANTHROPIC_API_KEY），或通过 --config 指定配置文件。
- GUI 依赖缺失：确保 Node.js v18+ 与 pnpm/npm 已安装；在 agent-diva-gui 目录下执行 pnpm install 与 pnpm tauri dev。
- Windows 服务问题：使用 agent-diva service 子命令管理服务生命周期。
