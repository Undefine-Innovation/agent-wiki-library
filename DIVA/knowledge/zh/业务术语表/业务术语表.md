### Clean Break
- 定义：Agent Diva 总 EPIC「Laputa 认知工作区 Clean Break」，代号 P0，包含 D0–D4 架构决策门、S1–S6 实施阶段及机器证明门，当前代码实施基本完成，卡点在真实桌面视觉验收。
- 别名：Laputa 认知工作区 Clean Break

### BML
- 定义：Basic Memory Layer，Agent Diva 的记忆存储层，以 profile-local SQLite + FTS5 数据库为唯一生产记忆权威，Laputa 治理层建立在其之上。
- 别名：基础记忆层

### Laputa
- 定义：Persona 治理层，位于 BML 之上，提供提案（proposal）、governed apply、回滚、审计以及 Frozen Core persona 基线，所有权威状态写入必须经 `apply_proposal()` 路径。

### AutoDream
- 定义：自动提案生成器，按调度运行蒸馏流程产出 Laputa proposal，但从不直接写入 persona 状态；变更需经 GUI Evolution 或 CLI 审批后 apply。

### 伙伴（原桌宠/宠物）
- 定义：GUI 中的桌面虚拟形象功能，已完成从「桌宠/宠物」到「伙伴」的全仓改名（包括 Rust 侧 `MateConfig`、GUI 特性树 `diva-mate`、Tauri 窗口标签、HTML 入口、locales 文案），旧 `pet` 配置键通过 serde alias 与 localStorage 迁移兼容。
- 别名：桌面伙伴、Desktop Mate、diva-mate、MateConfig

### HITL
- 定义：Human-in-the-loop 审批机制，沙箱执行与工具调用前的用户确认流程，可通过 CLI `agent-diva approvals` 或 GUI Approval Center 查看与处理。
- 别名：人工审批、审批中心

### Workspace / AGENTS.md 注入
- 定义：将 `<workspace>/AGENTS.md` 以 `## Agent Rules` 段落注入系统提示的工作区能力，已实现根文件读取、4000 字符预算上限与 session 缓存失效；但 `WorkspaceInstructions` 模块提取、安全合同、Codex 风格 CWD、GUI 工作区选择页等仍停留在研究包阶段未授权施工。
- 别名：工作区注入、WorkspaceContext

### EPIC 新启动
- 定义：TODOLIST 中的一个管理分区，收录研究包已收敛但尚未开工的独立工作区（如 EVENTBUS-TRAIT-HOOKS、HARNESS-SESSION-ADMISSION-BOUNDED-QUEUE、CLARIFY-HITL Phase 3），与存量延续工作区相互独立，启动时需按 LOCK.md 流程另行建锁。

### 待决策事项
- 定义：TODOLIST 中「先拍板、后实施」的独立分区，包含全仓库清理提案、day/hour token 熔断安全阀、Workspace CLI managed-path 契约、GUI-STYLE-UNIFICATION-PHASE-2 决策点等，决策落定前不启动对应批次。

### 真机冒烟
- 定义：在真实桌面环境执行的端到端冒烟测试批次，用于验证频道下架/编辑器、QQ、技能市场、M3-HITL、沙箱保存、Clarify、Gateway 端口、Provider 错误重试、Memory CRUD id 等功能，通过后相关条目可归档关闭。
- 别名：桌面冒烟、real-device smoke
