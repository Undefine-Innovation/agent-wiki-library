- 每个通道文件定义一个 `*Handler` 结构体并实现 `base::ChannelHandler` trait，内部组合 `BaseChannel` 复用白名单校验与入站消息发送逻辑。
- 通道通过 `Cargo.toml` 中的 `channel-*` feature 与 `#[cfg(feature = "...")]` 条件编译引入，`lib.rs` 与 `manager.rs` 中同步使用相同 feature gate 声明模块与 handler 类型。
- `ChannelManager::channel_validation` 集中维护各通道必填字段清单，通过 `required_fields` 辅助函数检查空字符串配置项并返回缺失字段列表。
- 通道初始化遵循固定模式：先调用 `channel_validation` 判断 ready，再构造 handler、注入 inbound sender、插入 handlers map，并在失败时通过 `log_skipped_channel` 记录警告日志。
- 入站消息统一经 `BaseChannel::handle_message` 包装为 `InboundMessage`，附加 media 与 metadata 后通过 `inbound_tx` 异步发送，禁止通道直接操作 bus。
- HTTP 客户端通过 `common::create_http_client` 统一创建并设置 30s 超时，避免各通道各自配置 reqwest 参数。
