- 每个工具独立一个 `.rs` 文件，定义一个 `pub struct XxxTool` 并在 `lib.rs` 中 `pub use` 暴露，形成“一工具一文件”的扁平结构。
- 工具实现统一通过 `#[async_trait] impl Tool for XxxTool` 实现 `name`/`description`/`parameters`/`execute` 四个方法，参数解析采用 `serde_json::from_value` 反序列化为具名结构体。
- 可选依赖（如 `MemoryProvider`、`SkillHome`、MCP 客户端）以 `Option<Arc<...>>` 形式注入，未配置时在 `execute` 中返回友好的失败 JSON 或 `ToolError::ExecutionFailed`。
- 工具输出统一经 `serde_json::to_string` 序列化为字符串返回，错误路径统一映射到 `ToolError::InvalidArguments` / `ToolError::ExecutionFailed`。
- MCP 相关 I/O（list_tools、call_tool、start/shutdown）全部用 `tokio::time::timeout` 包裹，超时统一转换为 `McpError::Timeout`。
- 测试集中在模块末尾的 `#[cfg(test)] mod tests` 中使用 `#[tokio::test]` 编写，并通过临时目录构造隔离环境。
