- 平台特定脚本通过检测运行环境（如 `uname`、`platform.system()`）选择目标架构与工具链，并在缺失依赖时给出明确错误提示而非静默失败。
- CI 打包脚本统一输出带元数据的 bundle 结构：包含 `bin/`、README、以及按 OS 条件注入的 `systemd/` 或 `launchd/` 目录，并生成 `bundle-manifest.txt` / `gui-bundle-manifest.json` 描述产物。
- 对外部命令（cargo、pnpm、curl、sqlite3 等）在执行前显式检查存在性，缺失时抛出清晰异常并中止流程。
- 从远程 API 拉取数据时通过 `Authorization: Bearer <env>` 头传递密钥，未设置必需环境变量时直接报错退出，避免泄露空凭据。
- YAML 清单更新采用“读取→解析→增量合并/替换→写回”的模式，并提供 `--dry-run`、`--sort`、`--keep-existing` 等安全开关以便审查变更。
- PowerShell 脚本使用 `Set-StrictMode -Version Latest`、`$ErrorActionPreference = 'Stop'` 并以函数封装步骤（Write-Step、Assert-Command），保证可中断且可复用的流水线行为。
