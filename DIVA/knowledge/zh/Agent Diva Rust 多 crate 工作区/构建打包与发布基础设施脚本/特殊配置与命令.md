- macOS 打包：运行 `scripts/package-macos.sh`，需先 `brew install create-dmg`，输出 `dist/*.tar.gz` 与可选 DMG。
- Linux 打包：运行 `scripts/package-linux.sh`，输出 `dist/agent-diva-<version>-linux-x86_64.tar.gz` 及 `.sha256`。
- Windows GUI 打包：`pwsh -File scripts/package-windows-gui.ps1`，支持 `-SkipCargo`、`-SkipPrepare`、`-SkipNsisPrecache`、`-SkipPnpmInstall` 参数；首次运行会下载 NSIS 3.11 与 `nsis_tauri_utils.dll` 至 `%LOCALAPPDATA%\tauri\NSIS`。
- macOS GUI 打包：`scripts/build-macos-gui-bundle.sh`，依次执行 cargo 构建、`prepare_gui_bundle.py --target-os macos`、`pnpm tauri build`。
- 刷新模型清单：`python scripts/update_provider_models.py --providers openrouter [openai|deepseek|groq|aihubmix] [--dry-run] [--sort] [--keep-existing]`，需设置对应 `*_API_KEY` 环境变量。
- crates.io 版本可见性等待：`CRATE=... VERSION=... ./scripts/wait-crates-io-version.sh`，默认最多轮询 60 次、间隔 10 秒。
- Feature gate 校验：`python scripts/feature-gate-check.py`，对 `agent-diva-sandbox` 的多组合 feature 执行 `cargo check`。
