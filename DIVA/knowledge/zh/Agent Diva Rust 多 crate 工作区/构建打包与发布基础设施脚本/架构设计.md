本模块按职责划分为四个子目录：
- `scripts/`：顶层构建与工具脚本，包括各平台打包入口（`package-macos.sh`、`package-linux.sh`、`package-windows-gui.ps1`、`build-macos-gui-bundle.sh`），通过调用 `cargo build`、`pnpm tauri build`、`create-dmg`、`lipo` 等外部工具完成产物组装；Windows GUI 打包由 PowerShell 脚本驱动 Tauri 并预缓存 NSIS 工具链。
- `scripts/ci/`：CI 专用 Python 工具，`package_headless.py` 将已编译二进制与 `contrib/systemd`、`contrib/launchd` 中的服务文件打包为带 `bundle-manifest.txt` 的归档；`prepare_gui_bundle.py` 将 CLI/Service 二进制拷贝到 `agent-diva-gui/src-tauri/resources/bin/<os>/` 并生成 `gui-bundle-manifest.json`，供 Tauri 嵌入安装器。
- `scripts/e2e/scenarios/`：以 YAML 声明式描述端到端测试用例（消息、断言），作为被测系统的输入契约。
- `contrib/{systemd,launchd}`：系统服务单元与 install/uninstall 脚本，被 CI 打包脚本按目标 OS 条件复制进最终发行包。
- `scripts/archive/root-debug-artifacts/`：面向 Windows 的文件系统诊断与附件上传调试脚本，独立于主构建流程。
依赖方向单向：脚本 → cargo/pnpm/外部工具 → 仓库源码与 `contrib/` 资源，不反向依赖业务 crate。
