- 通过 Builder 模式（链式 `with_*` 方法）组装 `ToolAssembly`，再调用 `build()` 或 `build_subagent_registry()` 一次性产出 `ToolRegistry`。
- 对外部可替换组件（LLMProvider、MemoryProvider、CronService、FileManager、AskUserCoordinator 等）一律以 `Arc<dyn Trait>` 注入，便于测试与多实例复用。
- 子代理与主 agent 共用同一 `LLMProvider`，但通过独立的 prompt 构造函数（`build_subagent_prompt` / `build_isolated_subagent_prompt`）隔离系统提示与权限范围。
- 工具注册遵循“先注册、后过滤”的顺序：先根据 `builtin_config` 开关注册工具，再在末尾统一应用 mask 的 read-only、plan phase 白名单与 `tool_limits` 拒绝列表进行二次裁剪。
- 长输出统一走 `canonicalize_tool_result`：小于 `INLINE_THRESHOLD_CHARS` 直接 inline，否则通过 `ToolArtifactStore` 持久化并以 `ToolResultRef` 引用，避免污染消息上下文。
- 异步任务生命周期通过 `running_tasks: Arc<Mutex<HashMap<String, JoinHandle>>>` 集中追踪，任务结束时主动从 map 中移除句柄，防止泄漏。
