本模块是 agent-diva-agent 的运行时支撑层，围绕 `lib.rs` 暴露的公共 API（`ToolAssembly`、`SubagentSpawner`、`RuntimeControlCommand` 等）组织若干职责内聚的子文件：
- 工具装配 (`tool_assembly.rs`)：通过 Builder 模式收集 `BuiltInToolsConfig`、网络配置、MCP 服务器、规划阶段、掩码策略等，最终构建出带安全边界（read-only / workspace-only）、延迟激活（Deferred 分区）和 mask/tool_limits 过滤的 `ToolRegistry`；提供 `build()` 与 `build_subagent_registry()` 两条路径，后者显式剥离 persona、cron、spawn、attachment 等能力。
- 子代理 (`subagent.rs` + `subagent_run_handler.rs`)：`SubagentManager` 维护运行中的任务句柄、共享 LLM Provider 与 MemoryProvider，支持 `spawn`（后台 tokio::spawn）、`run_supervised`（前台等待完成并回写父 session token ledger）与 `spawn_batch`（JoinSet 限流并发，默认上限 `MAX_CONCURRENT_SUBAGENTS=4`）；`SubagentRunHandler` 实现 `RunHandler` 将 supervised run 路由到管理器。
- 记忆整合 (`consolidation.rs`)：基于 `Session.last_consolidated` 与 `DEFAULT_MEMORY_WINDOW` 触发，调用 LLM 产出 `save_memory` tool call，经 `QualityGate` 评分重试后以 itemized add/update/remove 写入 BML `MemoryProvider`，并对 WORLD-shaped 内容做丢弃保护。
- 技能发现 (`skills.rs`)：`SkillsLoader` 绑定 `{config_dir}/skills` 与内置 skills 目录，按 enabled/always 状态生成 C1 摘要与 D3 字符预算内的 always 上下文。
- 工作区指令 (`workspace_instructions.rs`)：读取根 `AGENTS.md`，计算 SHA-256 前缀并附加安全契约，输出 `WorkspaceInstruction`。
- 令牌估算 (`token_estimate.rs`)：采用 chars/4 × 4/3 ≈ chars/3 启发式对文本/消息进行快速 token 计数。
- 运行时控制 (`runtime_control.rs`)：定义热更新/会话管理/计划审批等控制面命令枚举。
- 工具结果归一化 (`tool_results.rs`)：统一将工具输出 inline 或持久化为 artifact 并通过 `ToolResultRef` 引用，支持 microcompact 压缩历史消息。
- 记忆边界 (`memory_boundary.rs`)：对外仅暴露 `default_memory_provider`，强制使用 `agent_diva_laputa::MemoryHome` 作为唯一长期记忆权威。
依赖方向单向向下：本模块依赖 `agent_diva_core`、`agent_diva_providers`、`agent_diva_tools`、`agent_diva_tooling`、`agent_diva_sandbox`、`agent_diva_files` 等外部 crate，内部各文件之间通过 `crate::` 相互引用（如 subagent → tool_assembly → tool_results），不向外暴露内部实现细节。
