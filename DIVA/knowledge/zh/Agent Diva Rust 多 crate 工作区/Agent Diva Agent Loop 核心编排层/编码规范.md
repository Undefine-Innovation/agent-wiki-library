- 对外暴露的公共 API 集中在 `src/lib.rs` 的 `pub mod` 与 `pub use` 白名单，内部实现细节保持 `mod` 私有。
- 所有外部 I/O（LLM 调用、文件读写、网络请求）均通过 trait 抽象（如 LLMProvider、MemoryProvider、ToolRegistry）注入，便于测试替换。
- 运行时配置通过 `ToolConfig` 聚合后以 builder 链式方式传入 `ToolAssembly`，避免构造函数参数爆炸。
- 每轮 turn 的工具能力通过 `ActiveToolSurface` + `ToolTurnOptions` 携带 mask、plan_phase、session_key、background_task_context 等上下文信息，确保同一 AgentLoop 实例在不同 session 间隔离。
- 安全与资源限制统一经由 agent-diva-core 的 `SecurityConfig`、`ActionTracker`、`RejectionCircuitBreaker` 在 AgentLoop 构造时加载并生效，不在子模块内重复实现。
- 异步任务通过 tokio::select! 同时监听 inbound 消息与 runtime_control 通道，保证控制命令优先于业务消息处理。
