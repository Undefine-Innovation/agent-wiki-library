- 对外构造器采用 builder 风格链式配置（`with_stale_lock_after` / `with_report_curation` / `with_skill_reflection_engine` / `with_memory_home` / `with_skill_home`），所有可选依赖通过 `Option<Arc<...>>` 注入。
- 运行状态机通过 `AutoDreamRunRecord` + `AutoDreamOrchestrationPhase` 持久化，每次阶段推进都调用 `transition_phase` 更新 phase 与 updated_at 并写回磁盘。
- 所有 I/O 错误统一包装为 `AutoDreamError::Io { path, source }`，并在读取失败时按语义转换（如 `NotFound` → `RunNotFound`）。
- 事件日志以 JSONL 追加方式写入 `events.jsonl`，每条记录包含 `id`、`run_id`、`kind`、`created_at` 及可选的 `phase`/`failure_code`/`proposal_id` 字段。
- 关键写操作（run record、checkpoint、lock）均通过 `atomic_write_json` 原子落盘，避免并发写入导致的部分文件损坏。
- Worker 阶段状态枚举（`AutoDreamReflectionStage`、`AutoDreamWorkerStageStatus`、`AutoDreamRestrictedAction`）统一使用 `#[serde(rename_all = "snake_case")]` 保持序列化稳定。
