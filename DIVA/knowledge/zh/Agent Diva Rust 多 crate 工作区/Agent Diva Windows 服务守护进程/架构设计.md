单二进制入口 `src/main.rs`，通过 `cfg(windows)` 条件编译将非 Windows 平台直接报错退出；Windows 分支在 `windows_impl` 模块内实现完整服务逻辑：使用 `clap` 解析 CLI（`--config-dir`、`--console`），通过 `windows-service` crate 的 `define_windows_service!` + `service_dispatcher::start` 注册名为 `AgentDivaGateway` 的服务，并在控制处理器中响应 Stop/Shutdown/Interrogate 事件。服务启动后调用 `spawn_gateway_child` 以 `agent-diva.exe gateway run [--config-dir ...]` 形式拉起同目录下的网关可执行，并通过 `mpsc` 通道与轮询 `try_wait` 循环实现“子进程退出或收到停止信号即终止”的双端点退出机制；期间按 `StartPending → Running → StopPending → Stopped` 状态机上报服务状态。日志通过 `tracing-subscriber` 初始化，目标过滤由 `RUST_LOG` 环境变量控制。依赖全部来自 workspace 共享配置，无内部子模块。
