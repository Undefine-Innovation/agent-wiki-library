- 通过 `cfg(windows)` / `cfg(not(windows))` 对 `main` 进行平台分支，非 Windows 路径仅解析参数后立即返回错误。
- 所有外部 I/O 调用（文件、进程、服务状态）均使用 `anyhow::Context` 包装并附带上下文信息以便定位失败原因。
- 服务状态变更统一通过 `service_status(ServiceState::...)` 辅助函数构造 `ServiceStatus` 并调用 `set_service_status` 上报。
- 日志初始化集中放在 `init_logging`，使用 `EnvFilter::try_from_default_env()` 允许通过环境变量覆盖日志级别。
