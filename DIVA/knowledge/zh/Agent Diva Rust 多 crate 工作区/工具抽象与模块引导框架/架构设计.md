本 crate 是 agent-diva 工具栈中最窄的对外契约，仅依赖 `agent-diva-core` 暴露基础类型（MessageBus、Config、PresenceState、SecurityPolicy、AuditEvent、ErrorContext），不引入任何具体工具实现。
- `base.rs` 定义核心抽象：`Tool` trait（name/description/parameters/to_schema/execute/validate_params/timeout_secs）、`ToolError` 枚举及其 `CategorizeError` 分类与稳定 code 映射，以及 `Result<T>` 别名。
- `registry.rs` 实现 `ToolRegistry`：以 HashMap 存储已注册工具，按 `ToolSchemaPartition::{Core, Deferred}` 分区管理 schema；通过 `DeferredToolActivationHandle` + `ActiveDeferredTools` 维护任务级可搜索的延迟激活工具集（上限 `MAX_ACTIVE_DEFERRED_TOOLS=8`），并提供 `search_deferred` 关键词打分排序、`get_definition_set` 输出带稳定 CORE 前缀的 OpenAI function schema、`execute`/`execute_structured` 统一执行路径（参数校验 → 超时控制 → 输出 sanitization → audit 审计）。
- `module.rs` 定义模块化运行时骨架：`ModuleCtx` 注入 bus/security/config/presence；`Module` trait 声明 name/start/stop/dependencies/on_config_reload；`ModuleRegistry` 用 Kahn 算法做拓扑排序并检测循环/缺失依赖；`Bootstrap` 负责按依赖顺序启动并在失败时反向回滚 stop。
- `lib.rs` 作为门面仅 re-export 上述三模块的关键符号，保持对外 API 最小化。依赖方向单向指向 `agent-diva-core`，被上层 `agent-diva-agent`、`agent-diva-nano`、`agent-diva-tools` 引用。
