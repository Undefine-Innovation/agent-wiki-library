- 场景与断言通过 `serde_yaml` 反序列化为带 `#[serde(default)]` 的结构体，缺失字段使用默认值（如 `timeout_secs=30`、`min_times=1`）。
- 断言类型统一以 `#[serde(tag = "type")]` 枚举表示，新增断言只需追加变体并在 `evaluate_single` 中匹配处理。
- 每个 scenario 的每个 message turn 都通过新建 `mpsc::unbounded_channel` + `drop(tx)` 的方式向 `EventCollector` 推送事件，确保 collect 能正确结束。
- 错误路径统一使用 `map_err` 包装为包含 `[scenario_name]` 前缀的可读字符串，保证单个场景失败不中断整个 run。
- Judge 断言必须走 `evaluate_assertions_with_judge` 异步路径，同步路径下直接返回失败的 safe-fail 结果。
- 配置集中通过 `E2EConfig::from_env()` 从环境变量加载并提供 `is_api_key_available()` 供上层做 skip 判断。
