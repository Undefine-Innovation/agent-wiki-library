模块以 `lib.rs` 暴露六个子模块：`config`（从环境变量加载 `E2EConfig`）、`types`（YAML 场景/消息/断言的序列化结构，使用 `#[serde(tag="type")]` 实现 tagged union）、`runner`（核心编排器 `ScenarioRunner`，负责发现 YAML 场景、创建临时工作目录、构建 `AgentLoop` + `MessageBus`、逐 turn 发送 `InboundMessage` 并通过 `mpsc` channel 收集事件）、`collector`（基于 channel 的事件聚合为 `CollectedEvents`）、`assertions`（对 6 种断言类型求值，其中 `Judge` 通过独立的 judge model 调用 LLM-as-Judge 返回 JSON verdict）、`tracer`/`report`（将 trace 写入 `trace_dir`）。依赖方向单向：`runner` → `collector`/`assertions`/`tracer`，所有外部交互均通过 `agent-diva-agent`、`agent-diva-core`、`agent-diva-providers` 提供的 `AgentLoop`、`MessageBus`、`LLMProvider` 抽象完成；`tests/` 下的 Rust 集成测试直接调用该库运行真实 LLM 场景。
