- 每个领域子模块在自身 `mod.rs` 中声明子文件并通过 `pub use` 重导出该域对外可见的类型，保持顶层命名空间整洁。
- 错误处理统一使用 `thiserror` 定义的 `Error` 枚举，并通过 `#[from]` 将 std/sqlx/config 等第三方错误转换为统一错误类型。
- 审计事件采用带 tag/content 的 serde 枚举（`#[serde(tag = "type", content = "data")]`），并通过 `emit()` 单点写入 `target: "audit"` 的 tracing 通道。
- 跨模块共享的标识符（如 workspace ID）通过纯函数（如 `canonical_workspace_id`）从输入派生，避免全局状态，且对 Windows/Unix 路径进行规范化以保证稳定性。
- 安全相关能力集中在 `security/` 子模块并按职责拆分（path、injection、pii、policy、skill、rate_limit、rejection_circuit 等），由外层 `mod.rs` 统一 re-export 常用类型。
- 配置与 schema 分离：`config/mod.rs` 负责加载，`schema.rs` 定义结构体，`validate.rs` 执行业务校验，形成加载→模式→验证的分层。
