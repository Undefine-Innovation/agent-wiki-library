模块以 `src/lib.rs` 为唯一入口，按职责划分为多个子模块：`bml` 暴露 `MemoryHome`/`TypedMemoryStore` 作为机器级 SQLite+FTS5 权威存储；`persona` 通过 `PersonaService` 维护单机的 Persona Markdown 工作区及变更请求；`frozen_core` 提供会话级 Frozen Core 快照投影；`actmem`、`feedback`、`memory_records` 分别承载活动记忆、无负载回忆反馈与旧版 section 迁移适配；`layout` 集中定义 `.laputa/` 目录结构（`state.json`、`locks/`、`recall-feedback.json`、离线 `memory.sqlite3`），并由 `LaputaStorage::open` 初始化；`atomic`、`lock`、`error` 提供原子写入、跨进程锁与统一错误类型。依赖方向单向向下：上层治理模块仅能通过 `bml`/`persona` 的公开 API 写入，禁止直接调用底层写接口，由 `tests/bml_boundary_guard`、`tests/direct_write_guard`、`tests/authority_boundaries` 等测试用例在编译期/运行期强制该边界。
