- 所有持久化路径通过 `LaputaPaths`/`LaputaStorage` 构造，禁止在业务代码中散落拼接 `.laputa/` 下的文件名。
- 对共享文件的并发访问统一经由 `LaputaLock` 加锁后再执行读写，避免绕过锁直接操作磁盘。
- 对外错误统一封装为 `LaputaError` 并通过 `Result<T>` 返回，IO 错误使用 `LaputaError::io` 包装来源。
- JSON 状态文件一律通过 `atomic_write_json` 原子落盘，保证状态一致性。
- BML 写入必须走 `TypedMemoryStore`/`MemoryHome` 的公开 API，禁止从治理层直接调用底层 `put`/`import_records` 等方法。
- 子模块采用 `mod.rs` 聚合再 `pub use` 重导出公共类型的方式暴露稳定接口，内部实现细节保持私有。
