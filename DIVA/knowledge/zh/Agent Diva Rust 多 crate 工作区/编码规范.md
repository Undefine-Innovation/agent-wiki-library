- 所有子 crate 通过 workspace.dependencies 引入共享 crate，禁止在子 crate 中重复声明版本
- 发布配置集中在根 Cargo.toml 的 [profile.release]（opt-level=3、lto=true、codegen-units=1、strip=true）
- 跨平台脚本通过 justfile 的 [windows]/[unix] 条件块区分 bash 与 powershell 执行环境
- 新增功能需通过 feature gate 隔离并由 scripts/feature-gate-check.py 验证各 feature 独立编译
- 关键架构边界（BML/Laputa/Cognitive Surface）通过独立 cargo test 用例强制断言，不得绕过
