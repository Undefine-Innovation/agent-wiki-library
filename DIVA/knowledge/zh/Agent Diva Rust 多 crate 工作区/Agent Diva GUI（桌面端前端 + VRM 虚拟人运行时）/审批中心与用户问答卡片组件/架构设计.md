模块由三个独立的 Vue 3 `<script setup>` 单文件组件构成，均通过 `defineProps`/`defineEmits` 暴露纯函数式接口，不持有业务状态。
- `ApprovalCenterCard.vue`：单个审批项的展示与操作单元，接收 `ApprovalView` 数据，内部计算 TTL 倒计时（每秒刷新 `now` ref）、风险等级样式（`risk-{level}`）、可执行动作（基于 `view.actions`）和 grant 粒度选择（once/session/rule），并通过 `inspect/decide/cancel/edit/refresh` 事件向上冒泡。
- `ApprovalCenterDrawer.vue`：右侧抽屉容器，使用 `Teleport to body` 渲染遮罩与对话框，实现键盘焦点陷阱（`trapFocus`）、ESC 关闭、按 risk 优先级 + expires_at 排序，并提供 domain/status/session 三栏过滤；内部复用 `ApprovalCenterCard` 并透传其所有事件为自身 emit。
- `AskUserQuestionCard.vue`：独立的用户问答卡片，定义本地 `AskUserQuestionView` 接口，支持单选按钮与可选的自由文本输入，通过 `answer/cancel` 事件回传答案。
依赖方向单向：Drawer → Card；三者仅依赖共享类型 `../api/approvals` 中的 `ApprovalView`/`ApprovalGrant`，无跨组件直接引用，便于在父级容器中组合使用。
