- 组件通过 `withDefaults(defineProps<...>(), {...})` 声明 props 并提供默认值，事件统一用 `defineEmits<{ (event: ..., payload): void }>()` 类型化声明。
- 所有用户可见文案通过 `t('approvalCenter.*')` 国际化 key 获取，不在模板中硬编码字符串。
- 异步/副作用通过 `onMounted`/`onBeforeUnmount` 管理定时器或资源（如 ApprovalCenterCard 的 TTL 秒级计时器）。
- UI 状态派生使用 `computed` 表达（如 remainingSeconds、terminal、visible、presentation），避免在模板中写复杂逻辑。
- 组件之间通过事件冒泡而非 prop 回调传递操作结果，保持子组件对父级 API 调用方式无感知。
- 样式采用 BEM 风格类名（如 `.approval-center-card`、`.drawer-header-actions`）并结合 CSS 变量控制颜色与间距，风险等级通过动态 class 绑定（`risk-{level}`、`status-{status}`）。
