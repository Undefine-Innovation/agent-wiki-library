本模块以 Tauri 为宿主进程（src-tauri），通过 Vite 构建三个入口：主窗口 index.html、桌面 Mate 模式 desktop-mate.html、嵌入 Mate 模式 embedded-mate.html；三者共享 src/ 下的 Vue 组件、composables、api、locales 等通用层，并通过 features/diva-mate 子域封装虚拟人能力。
- avatar-runtime-vrm 是独立 npm 包，封装 Three.js + VRM 渲染管线（scene-manager、motion-controller、expression-controller、speech/subtitle/ptt/vmc 控制器），对外暴露 vrm-runtime.ts 统一 API；features/diva-mate 通过其 runtime 接口驱动模型加载、表情、口型同步与动作播放。
- shared-avatar-protocol 是另一个独立 npm 包，集中定义 commands/events/types/runtime 四类 TS 类型与消息协议，被 avatar-runtime-vrm 与上层 Mate 逻辑共同引用，作为前后端/多进程间通信契约。
- src/api 通过 Tauri invoke 调用 Rust 命令（commands.rs 等），负责网关状态、计划、审批、Provider、Token 统计等后端能力；src/components 按业务域（chat/console/memory/planning/settings）组织 UI，并由 App.vue 路由到 NormalMode / ConsoleView / SettingsView / EvolutionView 等页面。
- 桌面 Mate 与嵌入 Mate 复用同一套 features/diva-mate 组件（DesktopMateApp / EmbeddedMateApp / DivaVrmAvatar），由各自 main 入口分别注入 Tauri 窗口上下文或 iframe 环境。
- 资源方面，public/vrm 存放默认 VRM 模型、动画与场景（home/sea/space.spz），由 Mate 服务按需加载。
