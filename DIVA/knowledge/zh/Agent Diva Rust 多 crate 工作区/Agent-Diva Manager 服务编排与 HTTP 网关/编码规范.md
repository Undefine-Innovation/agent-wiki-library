- HTTP 端点按功能拆分到 `src/handlers/` 下的独立 .rs 文件，并通过 `handlers.rs` 统一注册到 axum Router
- 所有跨请求状态集中在 `state::AppState` 中，handler 通过 `State<AppState>` 提取后访问单例 Manager
- 对外 API 仅从 `lib.rs` 显式 re-export 必要类型（Manager、GatewayRuntimeConfig、build_router、run_server、AppState、ManagerCommand），内部模块保持私有
- 配置与数据契约使用 serde 序列化格式（YAML/JSON），并通过 `data/` 目录或 fixtures 文件集中管理
