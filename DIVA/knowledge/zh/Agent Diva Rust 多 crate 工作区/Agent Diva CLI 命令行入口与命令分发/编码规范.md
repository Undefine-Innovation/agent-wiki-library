- 所有 CLI 子命令通过 clap derive 的 `Subcommand`/`Args` 枚举声明，并使用 `#[command(rename_all = "kebab-case")]` 统一 kebab-case 风格。
- 命令处理函数统一接收 `&CliRuntime` 引用，并通过 `runtime.loader().load()` / `workspace_context()` 获取配置与工作区，避免直接操作路径。
- 每个命令分支在进入时先判断 `structured_output`，仅在非结构化输出模式下打印 `info!` 日志或 ASCII logo，保证 JSON 输出不被污染。
- 状态/报告类数据结构统一使用 `serde::Serialize` 派生，以便同时支持人类可读文本与 `--json` 结构化输出。
- 可选项参数普遍成对出现（如 `--markdown`/`--no-markdown`、`--logs`/`--no-logs`），通过 `overrides_with` 实现互斥开关。
- 错误返回统一使用 `anyhow::Result`，并在需要结构化失败信息时转换为 `ApprovalCliResult { ok: false, reason_code }` 等形式输出。
