- 公共配置与策略类型统一使用 `#[derive(Serialize, Deserialize)]` 并以 `kebab-case` 重命名字段，便于从 TOML/JSON 配置加载。
- 模块通过 `#[cfg(feature = "...")]` 条件编译，并在 `lib.rs` 中以相同 feature gate 重新导出公共类型，使可选能力对调用方透明。
- 平台相关代码集中在 `src/platform/{windows,linux,macos}.rs`，通过 `cfg(target_os = ...)` 或 `cfg(windows)` 分支选择具体实现，对外仅暴露 `SandboxType` 与 `current_platform_sandbox_type()`。
- 构建型结构体（如 `SandboxCommand`、`SandboxExecRequest`、`SandboxAttempt`）采用 builder 风格方法（`with_env`、`with_timeout`、`with_approval` 等）进行链式构造。
- 决策类类型（`GuardianDecision`、`ApprovalRequirement`、`ReviewDecision` 等）提供 `is_*` / `requires_*` 谓词方法与 `new_*` 构造函数，配合 match 表达式驱动状态机流转。
- 日志输出统一使用 `tracing` 宏（`debug!`、`info!`、`warn!`），并按执行阶段（审批、策略评估、平台执行）分层记录上下文信息。
