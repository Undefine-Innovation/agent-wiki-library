模块以 `lib.rs` 为统一入口，按职责拆分为多个子模块：`manager::FileManager` 是对外主接口，编排 store/read/cleanup/soft-delete 等流程；`storage::FileStorage` 封装实际字节写入与 SHA-256 计算；`backend::StorageBackend` trait + `LocalStorageBackend` 实现将物理存储抽象化，便于未来接入 S3 等远端后端；`index::SqliteIndex`（别名 `FileIndex`）使用 sqlx 连接 SQLite 持久化元数据，支持软删除（`deleted_at`/`deleted_by`）、过期清理与从旧 JSONL 格式的迁移；`hooks::HookRegistry` 在 store/read/cleanup 各阶段注入可插拔钩子（压缩、加密、权限检查等）；`handle` 定义 `FileHandle`/`FileMetadata`/`FileIndexEntry` 等核心值类型；`channel` 在共享存储之上提供频道级文件关联；`config` 集中管理数据目录、最大文件大小、清理策略等配置。依赖方向单向：manager → storage/index/hooks/backend，所有 I/O 通过 tokio 异步完成，错误统一收敛为 `FileError`。
