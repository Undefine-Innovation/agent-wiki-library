- 所有对外 API 返回 `Result<T, FileError>`，并通过 `thiserror` 派生错误枚举，IO/序列化/数据库错误统一映射到 `FileError` 变体。
- 文件以 `sha256:<hash>` 形式作为唯一标识，存储路径按哈希前两位分片（如 `ab/cdef...`）以避免单目录文件过多。
- 写操作采用临时文件 + rename 的原子写入模式，读/删操作均先检查存在性再执行。
- SQLite 表通过 `include_deleted` 参数区分活跃与已软删除记录，软删除仅设置 `deleted_at`/`deleted_by` 而不物理移除。
- 生命周期关键路径（store/read/cleanup）通过 `HookRegistry` 调用 before/after 钩子，钩子失败或拒绝时由上层统一处理并返回错误。
- 测试统一使用 `tempfile::TempDir` 构造隔离的数据目录，配合 `#[tokio::test]` 验证 store/get/dedup/cleanup/soft-delete 等行为。
