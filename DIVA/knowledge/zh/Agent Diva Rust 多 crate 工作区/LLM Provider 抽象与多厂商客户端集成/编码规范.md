- 每个厂商客户端都通过实现 `base::LLMProvider` trait 暴露统一接口，并以 `OpenAiCompatibleClient` / `AnthropicClient` 等具名结构体持有 reqwest Client、api_base、extra_headers 等连接参数。
- 对外错误统一收敛为 `base::ProviderError` 枚举，并通过 `CategorizeError` 将 HTTP 5xx/429/timeout 映射到 `Retryable`、`Timeout`、`Fatal`、`Config` 等类别供上层重试策略消费。
- 流式响应统一使用 `StreamingUtf8Decoder` 累积 chunk 并按完整 UTF-8 字符边界输出，避免 SSE 分片导致的乱码。
- 可插拔横切关注点（审计、速率限制、重试回调、最终 wire 缓存监听）通过 `set_retry_listener` / `set_final_wire_cache_listener` 以及 `ProviderTap` 装饰器注入，而非修改核心客户端。
- 模型能力判断采用保守白名单：`model_capabilities_for_model` 对未知模型默认返回 `text_only()`，仅显式列出的模型才启用 vision/reasoning/context_window。
- Provider 元数据集中声明于 `src/providers.yaml`，由 `ProviderRegistry::default_providers` 编译期 include 并解析，新增厂商无需改动 Rust 源码即可被 registry 发现。
