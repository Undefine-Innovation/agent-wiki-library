顶层 Cargo.toml 声明 workspace members，将所有子模块（core、agent_loop、autodream、channels、cli、e2e、files、gui、laputa、manager、migration、neuron、providers、sandbox、service、tooling、tools、docs、scripts_and_infra）纳入同一依赖图；workspace.dependencies 集中锁定 tokio、serde、reqwest、tracing、clap、sqlx 等跨 crate 共享版本，确保所有子模块使用一致的异步运行时、序列化与 HTTP 栈。CLI（agent-diva-cli）作为用户入口，通过 clap 子命令分发到 core/agent_loop；GUI（agent-diva-gui/src-tauri）内嵌 Manager（agent-diva-manager）作为 HTTP Gateway；Manager 再编排 Laputa、Sandbox、Tooling、Providers 等子服务。justfile 提供 build/test/check/e2e-test/ci 等统一入口，并串联 feature-gate-check、laputa-clean-break-check、cognitive-clean-break-check、bml-boundary-check 等边界校验脚本，形成跨 crate 的发布门禁。
