- 对外 API 通过 `lib.rs` 统一 re-export（`NeuronEvent`、`LlmNeuron`、`NeuronError`、`NeuronNode`、`NeuronRequest`、`NeuronResponse`），模块内其余类型保持私有。
- 所有可序列化的结构体与枚举均派生 `Serialize`/`Deserialize`，并通过 `#[serde(default)]` 标注可选字段以保证向后兼容。
- 流式执行采用 `Option<mpsc::UnboundedSender<NeuronEvent>>` 可选事件通道模式：当通道存在时发送 Started/Delta/Completed/Failed 事件，否则静默忽略。
- 错误统一收敛到 `NeuronError` 枚举，并通过 `thiserror` 的 `#[from]` 自动转换 provider 层的 `ProviderError`。
- 每个 neuron 实例在构造时生成稳定 `neuron_id`（`Uuid::new_v4()`），并在所有事件与响应中透传，用于 trace 关联。
