模块以 `lib.rs` 为入口，按职责拆分为四个子模块：`types.rs` 定义跨层契约 `NeuronRequest`/`NeuronResponse`（含 messages、model、max_tokens、temperature、metadata 等字段）；`node.rs` 通过 `async_trait` 声明 `NeuronNode` trait 及 `NeuronError` 枚举，暴露 `run_once` 与 `run_once_stream` 两个调用入口；`executor.rs` 提供默认实现 `LlmNeuron`，内部持有 `Arc<dyn LLMProvider>` 与自生成的 `neuron_id`，将 provider 的 `chat_stream` 流式事件聚合为最终响应，并可选通过 `tokio::sync::mpsc::UnboundedSender<NeuronEvent>` 向外推送生命周期事件；`events.rs` 定义 `NeuronEvent` 枚举（Started/TextDelta/ReasoningDelta/Completed/Failed），作为未来图级编排的内部协议。依赖方向单向向下：executor → node/types/events → agent-diva-providers，本 crate 不感知上层工作流，仅负责单次推理。
