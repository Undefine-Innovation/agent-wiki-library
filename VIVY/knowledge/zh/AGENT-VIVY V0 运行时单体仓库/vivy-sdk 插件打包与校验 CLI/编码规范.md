- CLI 命令通过 `Run(args)` 内部分发器按首参字符串路由到 `verify`/`pack`/`inspect-artifact`，未知命令返回退出码 2。
- 所有错误以 `fmt.Errorf("sdk: ...")` 前缀包装，便于区分 SDK 自身错误与下游错误。
- 白名单枚举（`Seam`、`Grant`、`Effect`）统一提供 `Valid()` 方法并通过 switch 显式列出允许值，manifest 校验一律调用该方法。
- `vivy-plugin.json` 中每个字段均有独立的正则或集合校验（name/version/seam/grant/effect/schema），并将问题累积到 `[]string` issues 后一次性返回。
- 打包流程先 `Verify` 再 `loadManifest` 再 `pluginPackageName`，任一阶段失败即中止，避免产生不完整产物。
- 测试覆盖采用 bad-case 驱动：`internal/testdata/<scenario>/` 下成对放置 `plugin.go` 与 `vivy-plugin.json`，由 `*_test.go` 断言校验失败。
