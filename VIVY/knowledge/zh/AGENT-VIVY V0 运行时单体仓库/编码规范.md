- 单一 Go module 约束：所有 internal/*、cmd、sdk 同属 agent-vivy 模块，禁止拆分为多 module workspace
- Eino 使用边界：仅 internal/runtime 与 internal/provider 可 import github.com/cloudwego/eino*，domain 与上层不得反向依赖
- 领域契约隔离：Session/Message/Run/RunEvent 等 domain 类型作为跨层稳定契约，Eino 与 reference-project 类型不泄漏至 RPC/UI 层
- 存储后端抽象：storage 包通过 contracts.go 定义接口，SQLite 与 Postgres 以同构实现替换，由 config 选择启用
- Secrets 零持久化：Provider Key 仅驻留环境变量或内存，任何配置加载路径不得落盘敏感字段
- 运行期语义约束：每个 Run 必须产生且仅产生一个 terminal 事件，事件序列通过 events bus 的 after_seq 游标回放
