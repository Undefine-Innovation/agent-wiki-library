本仓库采用单一 Go module（agent-vivy）按 internal/* 划分职责：internal/app 作为装配入口负责生命周期与 worker 调度；internal/runtime 是唯一的 Eino 使用层，对外暴露 Run/Session/Message/RunEvent 等 domain 类型，并通过 internal/provider 的 openai-compatible / anthropic / mock 适配器桥接模型；internal/storage 定义 Journal/SnapshotStore/BlobStore/LeaseStore 契约并提供 SQLite 与 Postgres 两种后端；internal/rpc 提供 UI 侧 JSON-RPC 控制面；internal/events 实现事件 fan-out；internal/tools 注册 ToolSpec 并接入审批策略；internal/pluginhost 承载插件宿主；internal/studio 与 internal/studiocore 构成 Studio 外壳；cmd/vivy 产出物种二进制，sdk/ 产出独立的 vivy-sdk verify/pack 工具。依赖方向严格单向：仅 runtime 与 provider 可依赖 github.com/cloudwego/eino*，domain 不得反向引用 eino，Eino 及参考项目类型不泄漏到 UI 契约。
